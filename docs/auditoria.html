4 · Escalabilidad

Veredicto (respondiendo a la pregunta real): el código no está preparado para 100.000 usuarios concurrentes sin romperse ni lagearse. No es un juicio sobre si el plan gratuito alcanza hoy: los límites de Spark/Free se dejan al final como contexto. Los tres bloqueantes del lado del código son listados completos y conteos recalculados, fan-out de refetch sin dedupe ni abort y precache que anula el code splitting. El orden de ataque es P0 paginación + agregados + índices, después P1 canales, SWR y sync, y por último P2 precache y cota local.
